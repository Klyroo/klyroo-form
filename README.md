# Lux.Form (LuxStack)

TanStack Form equivalent for .NET, Blazor, and .NET MAUI:
- **`Lux.Form.Core`**: 100% Headless C# schema-driven form engine (`FormSchema`, `FormController`, `FormService`, reactive conditions, dirty diffing, validation triggers, multi-step wizard with `SkipWhen`, array fields, section completion status).
- **`Lux.Form`**: Blazor & MAUI Hybrid components (`BxFormEngine`, `BxFormPage`, `BxFormProvider`, `AddLuxForm()`).
