# Klyroo.Form Skill

- Declare a form from a C# model with `FormSchema.For<TModel>(s => { ... })` in `Klyroo.Form.Core`. The builder returns a handle per field (`var company = s.Field(m => m.IsCompany)`), so a later condition points at it: `s.Field(m => m.CompanyName, f => f.Required(c => c.Get(company)).VisibleWhen(c => c.Get(company)))`. Keys follow the members and nested members give dotted keys.
- Settings are methods on the field builder: `Required`, `Label`, `Rule(value => ..., message)`, `RuleAsync(...)`, `DependsOn(handles)`, `Default`, `OnChange`, `VisibleWhen`, `DisabledWhen`. Kind-specific ones exist only for the types they fit: `AsTextarea`, `AsPassword`, `MaxLength` (string), `Range`, `AsSlider`, `AsRating` (numbers), `AsSwitch` (bool), `Options`, `AsRadio` (any), `Accept` (files). Structure: `Group`, `List` (repeatable rows: a row is written back into the item it was loaded from, so members that are not columns survive; a list is a direct member, inside `Group` for a nested one), `MultiSelect` (get its handle again with `schema.MultiSelect(m => m.Roles)`), `Step`, `Section`, `Card`, `Tabs`, model checks with `Validate`, and `Field<TValue>("key")` for a field that is not in the model.
- Run it with `new FormController<TModel>(schema, model)`: `Get(field)`, `TryGet`, `Set(field, value)`, `GetError(field)`, `CreateModel()`, `ApplyTo(target)`, `Rows(list)`, `ExportDraft()`, and `SubmitAsync(save, target)`, which writes the target, runs the checks and hooks, saves, and puts back the members it wrote when anything fails (what the hooks and the save step did is not undone). `Get` gives the default of the type, or an empty list for a list or a multiple choice, while a field is empty or holds text that is not a value; `TryGet` says which. Text that is not a value (a draft with `abc` in a date) is a field error in `Validate` and `SubmitAsync`, never an exception.
- Add the `Klyroo.Form.DataAnnotations` package and `s.FromDataAnnotations()` (or `UseDataAnnotations()`) to read `[Required]`, `[Range]`, `[Display]` and the other attributes and to run `IValidatableObject` at submit.
- For a form described as data (built at runtime, values keyed by name) use the runtime mode in `Klyroo.Form.Dynamic`: `DynamicFormSchema`, `DynamicFieldSchema`, `DynamicFormController`, `DynamicFormService`, and the components `KlyDynamicFormEngine`, `KlyDynamicFormPage` and `KlyDynamicFieldView`.
- Render a typed form with `<KlyFormEngine Schema="schema" Model="model" OnSave="SaveAsync" />` (or `KlyFormPage` for sections; `TModel` is inferred, keep the schema in a field and the model non-null). `OnSave` gets the model, `OnSubmit` is `EventCallback<TModel>`, a submit writes into `Model` all or nothing. Draw one field in your own layout with `<KlyFormFieldView Field="@handle" />` inside the form component or a `CascadingValue` of the controller. Draw a control with `<KlyFieldTemplate Field="@handle" Context="c">` (a `FormControlContext<TValue>`: `Value`, `Set`, `Commit`, `Blur`, `Id`, `Error`, `Text`, `SetText`), or declare `f.AsCustom("key")` and register `AddKlyrooForm(o => o.CustomField<TValue>("key", renderer))`.
- Register with `AddKlyrooForm()` and mount `KlyFormProvider` for overlays: `FormService.CreateFormAsync<TModel>(schema, model, mode)` returns `FormSubmitOutcome<TModel>`, `DynamicFormService` the runtime one.
- Save with `OnSave` (or `SubmitAsync(handler, ct)` in the runtime mode) so `IsSubmitting` stays true during the save and the form stays dirty on failure; use `SetFormError` for failures that belong to no field.
- Use `DependsOn` for cross-field rules, async rules for per-field checks that need I/O, `KlyFormNavigationGuard` with `ExportState()` or `ExportDraft()` and `RestoreDraft()` for unsaved changes, `FormFieldKind.Custom` and `FormFieldKind.File` for other controls.
- Both controllers implement `IFormRuntime`: `Fields` lists `IFormFieldAccess` with `TrySet(JsonElement)`, `WriteValue(Utf8JsonWriter)`, `Clear`, `Toggle` and `Reset`, for agents.
- Texts and validation messages follow the Klyroo.UI locale: change them with `AddKlyrooForm(f => f.Texts("fr", t => t with { ... }))`, or set `Messages` on the controller without Blazor.
