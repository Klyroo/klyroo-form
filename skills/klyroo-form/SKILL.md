# Klyroo.Form Skill

- Use `Klyroo.Form.Core` (`FormSchema`, `FormController`, `FormService`) for headless schema-driven state, validation, dirty tracking, and multi-step wizards.
- Use `Klyroo.Form` (`AddKlyrooForm()`, `KlyFormEngine`, `KlyFormPage`, `KlyFormProvider`) for rendering inline, multi-section, or modal/drawer overlay forms.
