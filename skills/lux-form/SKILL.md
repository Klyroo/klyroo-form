# Lux.Form Skill

- Use `Lux.Form.Core` (`FormSchema`, `FormController`, `FormService`) for headless schema-driven state, validation, dirty tracking, and multi-step wizards.
- Use `Lux.Form` (`AddLuxForm()`, `LxFormEngine`, `LxFormPage`, `LxFormProvider`) for rendering inline, multi-section, or modal/drawer overlay forms.
