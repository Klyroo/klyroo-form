# Lux.Form Skill

- Use `Lux.Form.Core` (`FormSchema`, `FormController`, `FormService`) for headless schema-driven state, validation, dirty tracking, and multi-step wizards.
- Use `Lux.Form` (`AddLuxForm()`, `BxFormEngine`, `BxFormPage`, `BxFormProvider`) for rendering inline, multi-section, or modal/drawer overlay forms.
